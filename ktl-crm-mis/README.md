# KTL PVT LTD — CRM & MIS

A lightweight installable Progressive Web App for customer/lead tracking, tasks, follow-ups and basic MIS reporting.

## Open the app
After GitHub Pages is enabled for the parent repository, open:

https://devops-saurabhpandey.github.io/shivasha/ktl-crm-mis/

## Install on Android
1. Open the app link in Chrome.
2. Tap the ⋮ menu.
3. Choose **Install app** or **Add to Home screen**.

## Features
- Customer and lead records with status, expected value and follow-up date
- Task list with employee assignment, due date and status
- Dashboard metrics and conversion overview
- CSV export, printable/PDF reports, JSON backup and restore
- Offline app-shell caching after first successful load

## Important data note
This initial version saves data in the browser's local storage on one device/browser. It does not provide a shared multi-user database, logins, access controls, cloud sync, or server-side backups. Do not store sensitive customer data until authentication and secure shared storage are added. Export JSON backups regularly.

## Deploy
This app is a subdirectory of the shivasha repository and does not replace the main Shivasha app. GitHub Pages must be enabled for the repository for the URL above to work.
